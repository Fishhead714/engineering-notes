# engineering-notes

用 AI 干活的一些实践笔记：哪里出了问题、怎么发现的、之后怎么做。写给在工作中用 AI 的人，不需要技术背景。

Short essays (in Chinese) on working with AI agents: what went wrong, how it was found, and what to do instead.
